# Locate-Only-Updated

Locateo mod ported to 26.1 rewrite for early stages (WIP)Compared to the old version of locateo, the new version has added the/config locateo command for configuration, and added/lo and/locatently aliases (alias switches can be configured, use the/reload command to reload auto completion)

Open Config GUI:

    /configlocateo gui

Config with command:

    /configlocateo cmd locateo/locateonly/lo true/false

Depends:

Java25

Minecraft 26.1

Fabric Loader 0.19.3

Fabric API 0.155.2

Cloth Config API >26.1.154
